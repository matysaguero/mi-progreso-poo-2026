# Clase 10: clases anonimas, lambdas y adaptadores

- `actividad/`: proyecto Java de partida. Es el que hay que abrir y modificar.
  Arranca con el conversor de moneda de la clase 9, con un solo receptor
  para los dos botones y un if adentro.
- `ejemplo/`: el ejemplo de la pre clase completo y ejecutable, con las tres
  versiones del controlador de la caja: el if por fuente, una clase con
  nombre por boton, y lambdas con un KeyAdapter. Es para mirar, no para
  modificar.

La solucion se publica despues de la clase.
